# Tooltip

react-tooltip, dark by default (primary_black with white text), `radius-tooltip` (0.2rem), padding 1.4vmin 2vmin 1.1vmin, uppercase 1.4vmin text. `.lightTooltipBackground` uses primary_gray_4; `.whiteTooltipBackground` uses white with `boxShadow_card`; `.customTootipWidth` fixes it at 50vmin. Bootstrap `.tooltip-inner` uses `radius-0_5` and max-width 45vmin.

**Consumer provides:** short tooltip text; keep it to a phrase.
