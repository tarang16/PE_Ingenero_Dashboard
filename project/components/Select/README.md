# Select

react-select, re-skinned (`react-select-modifyDetails` / `react-selectTimezone` prefixes): control with 1px primary_gray_3 border and `radius-control`, no focus glow; menu with a 4px primary_gray_4 border and `shadow-menu`; selected option primary_blue with white text, hovered option primary_blue_60 with primary_gray text.

**Consumer provides:** options, the selected value and the class prefix.

- The menu sits in the `z-picker` band (9999+) so it shows above open modals.
