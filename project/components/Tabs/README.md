# Tabs

Standard Bootstrap tabs: flat, 6vmin tall, white, no bottom border; labels uppercase 1.4vmin primary_gray; hover and active get primary_gray_4 background and primary_blue text; `radius-0`.

**Consumer provides:** tab labels and which one is active (`.active`).

- For top-level page section switches with the brand's trapezoid silhouette use **TriangleTabs**.
