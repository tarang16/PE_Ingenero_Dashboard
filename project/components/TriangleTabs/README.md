# TriangleTabs

The distinctive trapezoid "pill" tabs (`.commonTriangleTabs`): `clip-path: polygon(2.5vmin 0, calc(100% - 2.5vmin) 0, 100% 100%, 0 100%)`, top corners `radius-pill` (3.5vmin), inactive on primary_blue_bg, active primary_blue with white text, overlapping by −1vmin with a drop shadow; the active tab stacks on top.

**Consumer provides:** tab labels and the active one.

- Use for the main efficiency dimensions (energy, process, environment) or other top-level section switches; keep to 2–5 tabs.
