# Loader

The product's animated SVG loaders, inlined so they animate (the copies in the **Loaders** asset group are static frames: the asset store strips SVG animation).

**Consumer provides:** a container; inline the loader's SVG markup (or reference the original file from the product repo, `src/assets/sabic_icons/loaders/`) centred in the loading region at 3.5–6vmin.

- `elips_loader` cycles between #1fb8f5 and #fdd432 — the brand blue and yellow.
- Full-screen loading overlays sit in the `z-picker` band (9999+).
