# DatePicker

react-datepicker inputs styled like **TextInput** (1px primary_gray_3, `radius-control`); the field being edited gets a 2px primary_blue border. Dates read `DD-Mon-YYYY` (e.g. 30-Oct-2024).

**Consumer provides:** start / end dates and which is active. Trend views pair it with range presets (1W, 1M, 2M, 3M, 6M, 1Y) where the active preset is primary_blue.
