Shared action and state icons: chart-type switches (area, bar, line, scatter), delete (bin, bin_blue, red_delete_icon), checks and crosses (green / red / gray), warnings (orange warning, blue_warning, white_warning), time info, download, email, history, ODS escalate arrows, tab images, the breadcrumb separator and the dotted_trend_primary_* legend keys (one per palette colour: blue, dark blue, gray_3, green, orange, white, yellow). Inks are named in the file names. blue_clock_icon_gray_background.png is a PNG render (its SVG embedded a raster). elips_loader.svg and loaderGray.svg are static frames here — see the Loader component.
